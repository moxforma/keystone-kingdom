Privacy

Plain-language version. Last updated October 2026.

The short version

  • Keyloria works without an account. No sign-up, no passwords and no emails are needed to play.
  • Progress is saved in your browser, on your device.
  • No ads. No tracking or analytics tools. We don't sell or share data.
  • Some data is sent to our server only when a grown-up turns on one of the optional features below.

Stays on your device

Player names, heroes, outfits, stars, Keylori, lesson progress, settings and typing stats are stored in your browser's local storage. Clearing your browser data, or using Settings → Start over, removes it.

Sent to our server (optional features)

  • Classes: when a child joins a class, we store the first name they type and their typing stats (lesson, stars, speed, accuracy, minutes). The class teacher can see this on their dashboard. Other kids in the class can see the class high-score board (first names and scores).
  • Races: the racer's first name, hero look and live progress, so everyone in the race can see the race. Race rooms close after 3 hours.
  • Family sync: if a grown-up turns it on, the game's save (player names, age group and progress) is stored under your private family code so it can sync between your devices.
  • Arcade challenges: when you share a challenge, the words, score and first name in that challenge are stored so the link works.
  • Feedback: only grown-ups can send feedback. We receive the message, its type, and an email address only if you type one.

Our server runs on Netlify, which, like any web host, receives your IP address when the game loads. We use hashed (scrambled) IP addresses only to slow down spam and code guessing, and we don't store them as-is.

Deleting data

  • Class: the teacher can delete a class in the Teacher dashboard (the ✕ next to the class). That removes every child's class data from our server. A child can also leave a class.
  • Family sync: turn it off in Settings.
  • Anything else: a grown-up can ask us through the Feedback button in the game, and we'll delete it.

For schools

Teachers create classes and see only the first names and typing stats of kids who join. Kids can't chat or message anyone. Teacher tools sit behind a grown-up check, and only the device that created a class can open its dashboard.
